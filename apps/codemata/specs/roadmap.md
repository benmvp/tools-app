# Codemata Roadmap

Last Updated: 2026-08-29

## Scope

This document tracks planned and proposed work for Codemata. It is not canonical for current implementation state.

Canonical current-state source: [current-state.md](current-state.md)
Canonical architecture rules: [architecture-contracts.md](architecture-contracts.md)

## Near-Term Priorities

- Expand high-value tool coverage where user demand is strongest.
- Continue improving metadata quality and social share previews.
- Keep AI-generated educational content quality and reliability high while preserving graceful fallback behavior.
- Maintain test signal quality as tool surface area grows.

## Workflow and Governance Improvements

- Adopt canonical living docs across all apps using the Codemata pilot format.
- Add agent-guided documentation checks that warn on source updates without canonical doc updates.
- Reduce spec drift by keeping planning content in roadmap docs only.

## Candidate Future Areas

- Additional generators and viewers with clear user demand.
- Further UX refinement for command palette discovery and cross-tool recommendations.
- Continued performance, accessibility, and SEO improvements as baseline quality guardrails.
